GPU (공유)

자동 기동 예약 (gpu-wait)

GPU 는 다른 사용자와 같이 씁니다. 예약하면 gpu-wait 가 다른 프로그램의 최근 2시간 최고 사용량을 빼고도 여유가 있을 때(5분 연속) 서비스를 올리고, 여유가 부족해지면 우리 서비스를 내립니다. 지금 바로 올리는 버튼은 두지 않았습니다.

CPU 시연

GPU 없이 두 Agent 화면을 확인하는 모드입니다. 가짜 LLM 과 가짜 Moshi 가 고정된 답을 합니다. 화면 흐름과 마이크, 끼어들기, 안전 필터를 확인하는 용도입니다.

시연은 7201·8001·8766 포트를 차지하므로, GPU 자동 기동 예약이 있으면 켜지 않습니다. 예약을 취소한 뒤에 켜세요.

접속 방법

모든 화면은 서버 안(127.0.0.1)에서만 열립니다. 직원 PC 에서 SSH 터널을 연 뒤 http://localhost:포트 로 접속합니다.

    3.

    4.

    5.
