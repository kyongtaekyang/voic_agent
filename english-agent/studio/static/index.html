참여자
동의 (녹음 전에 서면으로 받은 내용을 확인)

아동 녹음은 저장되지만, 내부관리규정 검토가 끝날 때까지 학습 데이터로 바뀌지 않습니다.

학습 활용 동의가 없으면 녹음만 저장하고 학습 데이터에는 넣지 않습니다.

녹음 방식

두 기기 모두 SSH 터널로 접속해야 하므로, 기기 2대 방식도 직원이 관리하는 기기에서만 씁니다. 집에 있는 학생은 지금 접속할 수 없습니다.

기타

    세션이 만들어졌습니다

      녹음 목록

      세션튜터 / 학생구분길이학습 동의상태

      삭제는 동의 철회에 쓰며, 녹음 파일과 그 녹음으로 만든 학습 데이터를 함께 지웁니다. 되돌릴 수 없습니다.

      사용 안내

      1. 접속: 이 화면은 서버 안(127.0.0.1:7103)에서만 열립니다. 각 기기에서 SSH 터널을 연 뒤 http://localhost:7103 으로 접속합니다. 브라우저는 localhost 나 HTTPS 에서만 마이크를 허용합니다. 
        ssh -p 2022 -L 7103:127.0.0.1:7103 yang@119.65.103.62
      2. 세션 만들기: 튜터가 "새 녹음"에서 가명과 동의를 입력하고 세션을 만듭니다.
      3. 순차 녹음 (기본): "순차 녹음" 링크에서 마이크 하나를 연결하고 녹음을 시작합니다. 튜터 차례부터 시작합니다. 튜터가 말을 마치면 튜터 완료, 학생이 말을 마치면 학생 완료를 누릅니다(스페이스 키도 됨). 이것을 반복하다가 녹음 종료를 누릅니다. 차례인 사람의 음성만 그 사람 트랙에 들어가고 상대 트랙은 무음이 되므로, 마이크 하나로도 채널이 깨끗하게 나뉩니다. 대신 겹쳐 말하기(끼어들기)는 기록되지 않고, 버튼을 누르는 동안의 간격이 대화 사이에 들어갑니다.
      4. 기기 1대: "기기 1대" 링크에서 튜터 마이크와 학생 마이크를 따로 고릅니다. 서로의 목소리가 상대 마이크에도 들어가므로, 마이크를 각자 입 가까이 두세요(핀 마이크, 헤드셋 마이크 권장).
      5. 기기 2대: 튜터는 튜터 링크, 학생은 학생 링크로 들어가서 마이크를 연결합니다. 두 사람이 모두 연결되면 튜터가 녹음을 시작합니다. 같은 방이면 '상대 음성 듣기'를 끕니다. 떨어진 곳에서 들으며 녹음하면 전달 지연만큼 주고받는 간격이 늘어난 채로 기록됩니다. 두 기기 모두 SSH 터널이 필요하므로 직원이 관리하는 기기에서만 씁니다.
      6. 끝내기: 튜터가 "녹음 종료"를 누릅니다. 튜터 화면이 닫혀도 녹음은 끝납니다.
      7. 학습 데이터: 녹음은 바로 학습 데이터가 되지 않습니다. 튜터 음성의 단어 타임스탬프(Transcribe 30B)를 붙인 뒤 python -m finetune.prepare from-studio 로 변환합니다.
