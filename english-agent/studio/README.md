# 튜터 녹음 스튜디오

사람 튜터와 학생의 대화를 브라우저에서 녹음하는 화면입니다. 영어 Agent의 튜터 말투 LoRA 학습 데이터(프롬프트 3절)를 모으는 데 씁니다. GPU를 쓰지 않으므로 운영 모드(`gpu-mode`)와 상관없이 언제든 띄울 수 있습니다.

## 1. 실행과 접속

```bash
~/pgm/voice_agent/ada-ops/studio start     # stop | status
```

- 서버는 `127.0.0.1:7103`에서만 열립니다. 녹음하는 기기마다 SSH 터널을 연 뒤 `http://localhost:7103`으로 접속합니다. 브라우저는 localhost나 HTTPS에서만 마이크를 허용합니다.

  ```bash
  ssh -p 2022 -L 7103:127.0.0.1:7103 yang@119.65.103.62
  ```

- 로그는 `ada-ops/logs/studio/studio.log`에 남습니다. `gpu-mode stop`은 스튜디오를 끄지 않습니다.

## 2. 메뉴

| 메뉴 | 내용 |
|---|---|
| 새 녹음 | 튜터·학생 가명, 학생 구분(성인/아동, 아동은 연령대), 동의 항목, 녹음 방식, 수업 주제, 보관 기한을 입력하고 세션을 만듭니다. 만든 뒤 접속 링크가 나옵니다 |
| 녹음 목록 | 세션별 길이, 학습 동의 여부, 상태를 보여 줍니다. 세션을 열면 녹음을 들을 수 있습니다. **삭제**는 동의 철회에 쓰며, 녹음과 그 녹음으로 만든 학습 데이터를 함께 지웁니다 |
| 사용 안내 | 접속 방법과 녹음 순서 |

## 3. 녹음 방식

moshi-finetune은 튜터 음성과 학생 음성이 서로 다른 채널에 있어야 학습할 수 있습니다. 그래서 두 사람의 음성을 따로 받습니다.

- **기기 1대 (학습 데이터용 권장):** 한 화면에서 튜터 마이크와 학생 마이크를 따로 고릅니다(USB 마이크 2개 등). 같은 방에서는 목소리가 상대 마이크에도 들어가므로 마이크를 각자 입 가까이 둡니다.
- **기기 2대:** 튜터는 튜터 링크, 학생은 학생 링크로 접속합니다. 같은 방이면 '상대 음성 듣기'를 끕니다(기본값). 떨어진 곳에서 서버가 전해 주는 상대 음성을 들으며 녹음하면, 각자 상대 말을 늦게 듣기 때문에 서버 시간축의 주고받는 간격이 전달 지연만큼 늘어납니다. Moshi가 느린 주고받기를 배울 수 있으므로 학습 데이터로는 권하지 않습니다. 이때는 헤드셋이 필수입니다.
- **접속 제한:** 모든 기기가 SSH 터널로 접속해야 하므로, 기기 2대 방식도 직원이 관리하는 기기에서만 쓸 수 있습니다. 서버 계정 정보를 학생이나 보호자에게 주면 안 됩니다. 집에 있는 학생이 접속하려면 인증이 있는 HTTPS 주소가 따로 필요하며, 아직 정하지 않았습니다.
- 학생 화면에서는 메뉴(녹음 목록 등)를 숨깁니다.
- 녹음 시작과 종료는 튜터 화면에서만 할 수 있습니다. 튜터 화면이 닫히면 녹음이 끝납니다.
- 잡음 제거와 자동 음량 조절은 끕니다(학습 데이터 품질). 에코 제거는 기기 2대에서 상대 음성을 들을 때만 켭니다.

## 4. 두 트랙 시간 맞춤

두 트랙은 서버의 같은 기준 시각에 맞춰 씁니다. 한 연결 안에서는 받은 프레임을 그대로 이어 씁니다. WebSocket은 TCP라서 네트워크가 잠시 멈춰도 프레임이 없어지지 않고 나중에 몰려 오기 때문입니다. 도착 시각에 맞춰 무음을 끼우면 몰려 온 음성이 실제보다 뒤에 놓이게 됩니다. 서버 시계에 맞추는 것은 처음 들어올 때와 다시 연결될 때뿐입니다. 결과는 `meta.json`의 `tracks`에 남습니다.

| 값 | 뜻 |
|---|---|
| `lead_pad_s` | 녹음 시작 뒤 늦게 들어온 만큼 앞에 채운 무음 |
| `gap_pad_s` | 연결이 끊겼다가 다시 들어온 동안을 채운 무음 (그 사이 음성은 없음) |
| `drift_s` | 기기 오디오 시계와 서버 시계의 차이. 양수면 기기가 빠름. 브라우저가 소리를 빠뜨리거나 기기 시계가 어긋나면 커집니다 |

`finetune/prepare.py from-studio`는 `drift_s`가 0.5초를 넘거나 `gap_pad_s`가 2초를 넘는 세션을 학습 데이터에서 뺍니다.

## 5. 동의와 아동 녹음

- 녹음 동의(튜터, 학생)가 없으면 세션을 만들지 않습니다. 서버도 확인하므로 화면을 거치지 않은 요청도 막힙니다.
- 아동은 **법정대리인 동의**와 **동의서 관리 번호**가 있어야 세션을 만들고 녹음을 시작할 수 있습니다. 녹음 시작 직전에 `meta.json`을 다시 확인합니다.
- 학습 활용 동의는 녹음 동의와 따로 받습니다. 동의가 없으면 녹음만 보관하고 학습 데이터로 바꾸지 않습니다.
- **아동 녹음은 저장되지만 학습 데이터로는 바뀌지 않습니다.** 프롬프트 3절에 따라 내부관리규정 검토가 끝난 뒤 `config/services.yaml`의 `finetune.allow_child_data`를 `true`로 바꿔야 학습 데이터에 들어갑니다.
- 이름은 가명만 씁니다. 연령은 생년월일 대신 연령대로 받습니다. 동의서 원본은 이 서버에 올리지 않고 관리 번호만 적습니다.
- 보관 기간 정책은 아직 없습니다. 보관 기한 칸은 정책이 정해지면 씁니다(자동 삭제는 아직 하지 않음).

## 6. 저장과 학습 데이터

- 저장 위치: `english-agent/queue/tutor/<세션>/{tutor.wav, student.wav, meta.json}` (24 kHz 모노 PCM16, 저장소 제외, 서버 밖으로 보내지 않음)
- 학습 데이터 변환: 튜터 음성의 단어 타임스탬프(`tutor_words.json`, Transcribe 30B)를 붙인 뒤 `python -m finetune.prepare from-studio`를 실행합니다. 타임스탬프 미들웨어 형식을 아직 확인하지 못해서, 지금은 모든 세션이 "tutor_words 없음"으로 건너뛰어집니다 (`finetune/README.md` 3절).
